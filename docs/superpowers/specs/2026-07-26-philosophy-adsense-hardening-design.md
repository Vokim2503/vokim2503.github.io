# 철학 앱 애드센스 심사 대응형 보완 설계

## 목표

현재 공개 중인 최신 버전 `philosophy-V1`의 룰렛·철학자·영상 기능과 시각 디자인을 유지하면서, Google이 앱을 발견하고 콘텐츠와 운영 주체를 이해할 수 있도록 심사 필수 요소를 보완한다. 철학 앱은 별도 사이트로 신청하지 않고, 이미 심사 요청된 `vokim2503.github.io` 도메인의 하위 콘텐츠로 포함한다.

## 대상과 범위

- 운영 URL: `https://vokim2503.github.io/philosophy-V1/`
- 애드센스 게시자 ID: `ca-pub-5598414628909120`
- 기존 철학 룰렛, 고민 선택, 철학자 갤러리, 영상 연결 동작은 변경하지 않는다.
- 별도 도메인 구매, 수동 광고 단위 배치, 앱 전면 재디자인은 범위에서 제외한다.

## 구조

### 검색 및 광고 연결

- `noindex, nofollow`를 제거하고 `index, follow` 정책과 canonical URL을 명시한다.
- 애드센스 계정 메타 태그와 공식 비동기 스크립트를 `<head>`에 추가한다.
- 광고는 자동광고가 판단하도록 하고, 룰렛 결과나 팝업 내부에 수동 광고를 넣지 않는다.

### 게시자 콘텐츠

- 앱 상단 또는 주요 조작부 주변에 서비스 목적을 짧고 명확하게 설명한다.
- 조작 영역 아래에 다음 고유 콘텐츠를 제공한다.
  - 앱 이용 방법
  - 여섯 철학자의 사상과 앱에서 제공하는 조언의 성격
  - 철학적 조언을 현실 문제에 적용하는 방법
  - 오락·성찰 목적이며 전문적인 의료·심리·법률·재정 상담을 대신하지 않는다는 안내
- 동적으로 표시되는 명언과 별개로, 크롤러가 읽을 수 있는 정적 HTML 콘텐츠를 둔다.

### 신뢰 및 탐색 요소

- 운영자 `행복칠TV`, 문의 경로, 개인정보처리방침, 이용 안내를 푸터에 표시한다.
- 기존 도메인의 공용 `privacy.html`과 `guide.html`을 재사용한다.
- 철학 앱에서 로또 메인으로, 로또 메인에서 철학 앱으로 이동할 수 있는 명확한 링크를 제공한다.
- 루트 `sitemap.xml`에 철학 앱 URL을 추가한다.

## 사용자 경험

- 기존 우주·회전목마 디자인과 핵심 조작 순서는 유지한다.
- 새 설명 콘텐츠는 기존 색상과 타이포그래피를 따르는 읽기 쉬운 카드 섹션으로 배치한다.
- 모바일에서 가로 스크롤이 발생하지 않고 링크와 버튼을 터치하기 쉽게 유지한다.
- 광고 로딩 실패가 앱 기능을 막지 않도록 광고 스크립트와 앱 로직을 독립시킨다.

## 검증 전략

- 정적 HTML 검증 테스트로 robots, canonical, 애드센스 게시자 ID·스크립트, 서비스 설명, 면책 안내, 개인정보·가이드·메인 링크의 존재를 확인한다.
- 사이트맵 테스트로 철학 앱 URL이 등록됐는지 확인한다.
- 기존 전체 테스트를 실행해 로또 QR 복원과 기존 기능의 회귀가 없는지 확인한다.
- 배포 후 공개 URL을 브라우저로 열어 제목, 설명 콘텐츠, 푸터 링크와 기존 선택 기능을 확인한다.

## 배포와 애드센스 처리

- 검증된 변경만 현재 기본 브랜치에 커밋하고 GitHub Pages에 배포한다.
- 같은 호스트가 이미 `리뷰가 요청됨` 상태이므로 애드센스 사이트를 중복 추가하거나 심사를 중복 요청하지 않는다.
- 배포된 철학 앱은 사이트맵과 내부 링크를 통해 현재 도메인 심사에서 발견될 수 있도록 한다.

## 완료 기준

- `philosophy-V1` 공개 화면에서 기존 핵심 기능과 새 설명·운영 정보가 함께 정상 동작한다.
- 철학 앱이 검색 허용 상태이고 canonical, 애드센스 계정 코드, 필수 정책 링크를 포함한다.
- 루트 페이지와 사이트맵에서 철학 앱을 발견할 수 있다.
- 모든 자동화 테스트와 배포 검증이 통과한다.
