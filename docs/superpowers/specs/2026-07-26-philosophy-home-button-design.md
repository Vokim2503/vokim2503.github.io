# 철학 앱 로또 홈 버튼 설계

## 문제와 원인

철학 앱에는 로또 홈 링크가 존재하지만 긴 설명 콘텐츠 다음의 푸터에 작은 텍스트 링크로만 배치되어 있다. 첫 화면에서는 보이지 않고 버튼 형태도 아니어서 사용자가 돌아가기 기능이 없다고 인식한다.

## 목표

`philosophy-V1`을 열자마자 로또 앱으로 돌아가는 명확한 탐색 버튼을 제공한다.

## 설계

- `philosophy-V1/index.html`의 `<main>` 시작 부분, 기존 철학 로고 앞에 상단 탐색 영역을 추가한다.
- 링크 문구는 `← 이슈 로또로 돌아가기`로 표시한다.
- 링크 대상은 같은 도메인의 루트인 `../`로 한다.
- 기존 푸터의 `이슈 로또 홈` 링크는 보조 탐색 경로로 유지한다.
- 버튼은 기존 다크·네온 테마를 따르되 본문과 명확히 구분되는 테두리, 배경, 포커스 상태를 제공한다.
- 모바일에서는 버튼이 충분한 터치 높이를 가지며 화면 너비를 넘지 않는다.

## 테스트와 검증

- 정적 회귀 테스트에서 상단 탐색 링크가 정확히 하나 존재하고 `../`로 연결되는지 확인한다.
- 링크가 푸터보다 앞에 배치되어 첫 화면 탐색 역할을 하는지 문서 순서로 검증한다.
- 전체 테스트를 실행해 철학 룰렛과 로또 QR 관련 회귀가 없는지 확인한다.
- 배포 후 공개 철학 앱에서 버튼 표시와 로또 홈 이동을 브라우저로 확인한다.

## 범위 제한

- 철학 룰렛, 영상 연결, 애드센스 코드와 설명 콘텐츠는 변경하지 않는다.
- 고정형 버튼이나 팝업은 추가하지 않는다.
